# 0.1.14 整章直譯與中斷診斷

日期：2026-10-15。

## 現場證據與判斷

Chrome 當前漫畫頁顯示已完成 29/29 張，Google 初譯保留；二段校正回報「串流中斷或取消，結果未知」。這表示請求已進入回覆讀取階段，當次失敗沒有在整章輸入的 60 張／800 區域／120 KB 檢查階段發生。

0.1.13 的 POST 等待上限為 90 秒，且串流 catch 將逾時、使用者取消與網路中斷合併成同一訊息。當次可見證據缺少中斷原因及耗時，90 秒逾時與伺服器斷線都仍是可能原因；沒有取得該請求原始時間資料前，不把其中任何一項列為確認根因。私人漫畫網址、原文與畫面留在本機。

另以最小測試確認大型診斷紀錄的獨立缺陷：合法章節提示加上兩段回覆摘錄，可能超過背景原有 150,000 字元限制。這會使已完成回覆的診斷保存失敗。本次調整上限並保留有界摘錄；此缺陷與現場所見的串流中斷分別記錄。

## 實作

- 已提交 Gemini 請求最多等待 180 秒，涵蓋回應標頭與完整串流；初始化另限 20 秒。中斷記錄原因、階段、耗時、等待上限及已讀字元數，結果未知維持人工解除鎖定。
- 新增整章直譯，先收齊全部日文 OCR，再送出同章原文、術語、前頁摘要與漫畫專屬指示。省略 Google 初譯與逐框 Google 請求，完整核對回覆後逐張嵌字。
- 每個暫時短 ID 對應本機固定的頁面與原始文字框；圖片雜湊、原文、譯文與章節順序另由指紋核對。缺漏、重複、額外區域與過期回覆均拒收；格式修正只對已完成回覆執行一次。
- 直譯使用獨立快取，可復用相容 Google OCR。開始前保留最多 30 份原文快照，避免寫入新模式快取時逐出尚未處理的原文。兩模式共用最多 30 份頁面快取政策；模式切換可能依該政策淘汰較舊項目。
- 全部譯文核對後先保存，再產生 PNG。重排中斷可續呈現；不變的整章可沿用結果。工作台可讀回直譯並保存人工修訂。
- 修正 PNG 解碼期間自然尺寸暫時為零，使最後一張被漏算為 28/29 的掃描問題。
- 新版 unknown 不抹除協定通過證據。舊版僅在本機仍有完整 30/30 通過進度，且受阻原因明確為結果未知時復用證據；已知 HTTP 403／429 或協定錯誤持續受阻。此處不解除任何未知輸入鎖。

UTC 09:38:00 開始操作前記時，09:39:24 已觀察並確認完成，端到端觀察上界約 84 秒。這包含本輪讀圖、OCR 快取復用、匿名翻譯、嵌字和觀察間隔，並非精確 API 耗時，也不代表重新 OCR 29 張的冷啟動速度。新直譯請求與舊的未知校正請求屬於不同作業；未自動重送原先請求。
